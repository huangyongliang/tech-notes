## 通关自测

先独立作答，再展开参考答案核对；简答题答出要点即算对。答对 ≥ 80% 即可进入下一关。

1. 【单选】以下哪个内存区域是线程共享的？
    - A. 程序计数器
    - B. 虚拟机栈
    - C. 堆
    - D. 本地方法栈
2. 【简答】双亲委派模型的加载顺序是什么？它带来什么好处？
3. 【单选】以低停顿为主要目标、停顿时间基本不随堆大小增长的 GC 是：
    - A. Serial
    - B. Parallel
    - C. ZGC
    - D. CMS
4. 【单选】持续采样 GC 情况（如每秒输出一次各代使用率）的命令行工具是：
    - A. `jstat`
    - B. `javap`
    - C. `jar`
    - D. `jshell`
5. 【简答】JIT 编译器的作用是什么？

<details markdown><summary>参考答案</summary>

1. C — 堆（以及方法区）是线程共享的，其余三个线程私有。
2. 类加载器先委派父加载器加载，父加载器无法加载时才自己加载；避免核心类被篡改、避免重复加载。
3. C — ZGC 的设计目标是亚毫秒级停顿，与堆大小基本无关。
4. A — 例如 `jstat -gcutil <pid> 1000`。
5. 把热点字节码编译成本地机器码并做优化，提高长期运行的性能。

</details>
