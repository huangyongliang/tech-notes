## 原创谜题：连接四个构建节点

节点 A、B、C、D 间候选连线及费用为 `AB:2, AC:5, AD:8, BC:3, BD:6, CD:1`。希望所有节点互相可达，并选出一棵总费用最小的树。为什么不能只给每个节点挑一条最便宜的线，就宣布解决？先理解「树」到底要求什么。

## 知识要点

### 树的几种等价刻画

对 `n≥1` 的有限简单无向图，下列条件等价：

- 连通且没有圈，即树的定义。
- 任意两点之间恰有一条简单路。
- 连通且边数为 n−1。
- 无圈且边数为 n−1。

两条不同的简单路会产生一个圈，故连通无圈推出唯一简单路；反向则由路的存在得到连通，由圈会给出两条路排除圈。

**为什么边数是 n−1？** 当 n 至少为 2，取一条最长简单路，其端点不能有路外邻点，否则可延长；也不能有除路上相邻点外的路内邻点，否则有圈。因此两端都是叶子。删去一个叶子及其唯一关联边，剩余图仍连通无圈；以 n 归纳，从单点 0 条边，得到 n 点 n−1 条边。

连通图如果有圈，删去圈上一边仍连通，反复删至树，故连通图至少有 n−1 条边。于是「连通且 n−1 边」不能再有圈；「无圈且 n−1 边」则由每个树分量的边数求和可知只有一个分量。完整论证用到了前提，不能只凭边数猜。

### 森林、生成树与桥

森林是没有圈的无向图，各连通分量都是树；有 n 个点、c 个分量的森林恰有 `n−c` 条边，包括孤立点分量。

生成树是包含原图全部顶点的树形子图。有限非空图有生成树当且仅当它连通；断开的图只能逐分量取生成森林。任何桥都必须出现在每棵生成树中，否则桥两侧无法相连。

树本身不要求选根、二叉、有序，也不等于二叉搜索树；BST、堆的实现已经在 [DSA](../../cs-basics/06-data-structures-algorithms/) 中。本关只讨论连接结构。

### 最小生成树与交换论证

给有限连通无向图的边附实数权重，在所有生成树中总权最小者叫 MST；边权可为负、零或正，和 Dijkstra 的非负限制无关。

**割性质**：把顶点分成两个非空部分，某条跨割边 e 是所有跨割边中权重最小者，则**存在**一棵 MST 包含 e。若它是严格唯一的最轻跨割边，则每棵 MST 都包含它。

证明：取任意 MST T。若 e 不在 T 中，把 e 加进去会形成唯一一个圈；圈上还有另一条跨同一割的边 f。删 f 加 e 仍是生成树，而且 `w(e)≤w(f)`，因此新树仍最优；若严格小于，则原 T 不可能最优。相同权重时不能直接宣称所有 MST 都包含任意指定的最轻边。

Kruskal 按权重从小到大考虑边，只收下不会在已选森林中形成圈的边。收下一条连接两个分量的边时，它是跨某个当前分量割的一条最轻边；交换时替换掉的边不在已选森林中，所以能保持「已有选择属于某棵 MST」的不变式。最终选满 n−1 条边即得到 MST。这里说明正确性，不重复并查集实现。

## 小例题

### 例一：手算并给出最优理由

按权重考虑：先选 CD 的 1，再选 AB 的 2，再选 BC 的 3，形成 `A–B–C–D`，总费用为 6。前三条都连接不同分量，各自符合安全选择；得到生成树后停止。

只说「我画了一棵费用为 6 的树」只能证明最优值不大于 6；交换论证和安全选择才说明不可能有更便宜的树。本例权重互异，因此还可进一步证明 MST 唯一，但唯一性不是求出一棵最优树的必要步骤。

### 例二：边数与最短路的两个陷阱

一个 3 点圈再加一个孤立点，共 4 点、3 边，却不是树，说明 n−1 边不是单独充分条件。

再看 `AB:2, BC:2, AC:3`：MST 选 AB、BC，总权 4；但从 A 到 C 的最短路是直接走费用 3 的 AC。MST 优化总网络费用，不保证每一对点之间走得最短。

## 通关自测

1. 一片森林有 11 个顶点、4 个连通分量，边数是多少？若仅知道一般图这两个数，能断言同样的边数吗？
2. 对 n 顶点树加一条原来没有的边，为什么恰好形成一个圈？
3. 一个三角形三条边权都为 1。每一条边都是某个割的最轻边，它是否必须在每棵 MST 中？
4. 证明：连通图的一条桥必须出现在所有生成树中。

<details markdown><summary>参考答案</summary>

1. 森林有 `11−4=7` 条边。一般图可能在某些分量含圈，所以至少为 7，但不一定恰为 7。
2. 原树中新增边的两端恰有一条简单路，加该边就构成一个圈。任何新圈必须使用新增边，因为旧图无圈；若存在另一个新圈，就会对应第二条旧简单路，与唯一性矛盾。
3. 不必须。任取两条边都是 MST，某条指定边可被省略；割性质在并列最轻时只保证某棵 MST 包含它。
4. 删除桥后，原图分成更多分量，桥两侧没有其他跨边。若生成树不含它，就不能连接两侧，与生成树连通矛盾。
