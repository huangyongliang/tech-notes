## 知识要点

### 集合与笛卡尔积

集合不计重复、没有顺序；序列计顺序，且可重复。`x ∈ A` 表示元素关系，`A ⊆ B` 表示 A 的每个元素都在 B 中；空集 `∅` 是每个集合的子集。

| 运算 | 含义 |
|------|------|
| `A ∪ B` | 属于 A 或 B |
| `A ∩ B` | 同时属于 A 和 B |
| `A \ B` | 属于 A 但不属于 B |
| `A × B` | 所有有序对 `(a,b)`，其中 a 属于 A、b 属于 B |
| `𝒫(A)` | A 的所有子集组成的集合，叫幂集 |

补集必须相对于一个全集 U，写为 `U \ A`。当 A、B 有限时，`|A × B| = |A||B|`；若 `|A| = n`，每个元素都有选或不选两种可能，所以 `|𝒫(A)| = 2ⁿ`。`∅` 与 `{∅}` 不同，前者没有元素，后者有一个元素。

### 二元关系与等价类

从 A 到 B 的二元关系是 `A × B` 的子集；A 上的关系是 `A × A` 的子集。写 `aRb` 表示有序对 `(a,b)` 属于 R。

| 性质 | 精确定义 |
|------|----------|
| 自反 | 对每个 a，都有 aRa |
| 对称 | aRb 推出 bRa |
| 传递 | aRb 且 bRc 推出 aRc |
| 反对称 | aRb 且 bRa 推出 a = b |

同时自反、对称、传递的关系叫**等价关系**，它把集合划分为互不相交且覆盖全集的等价类。理由是：自反保证每个元素属于自己的类；如果两个类有共同元素，对称与传递会迫使两类相等。

同时自反、反对称、传递的关系叫**偏序**，不要求任意两个元素可比较。例如集合之间的包含关系是偏序；`{a}` 与 `{b}` 可能互不包含。反对称不是「不对称」：相等元素仍然可以双向相关。

### 函数是有唯一性限制的关系

函数 `f: A → B` 要求 A 中**每一个**元素都有 B 中**恰好一个**输出。A 是定义域，B 是陪域；实际取到的输出组成像集 `f(A)`，像集不一定等于陪域。

- **单射**：不同输入不会有相同输出；等价地 `f(a)=f(b)` 推出 `a=b`。
- **满射**：陪域里的每个元素都被取到，即 `f(A)=B`。
- **双射**：既单射又满射，因此有从 B 到 A 的逆函数。
- 复合 `g∘f` 先算 f 再算 g，要求 f 的输出能作为 g 的输入。

## 小例题

### 例一：缓存分类为什么可行

产物为 `{a,b,c,d,e,f}`，平台标签依次是 `(X,Y,X,Z,Y,Z)`。定义 aRb 当且仅当二者平台标签相等。标签相等具有自反、对称、传递性，因此等价类是 `{a,c}`、`{b,e}`、`{d,f}`。

如果改成「体积不超过」，通常不对称，不能当等价关系；若两个不同产物体积相同，双向「不超过」也不推出产物本身相等，因此在产物集合上甚至不一定反对称。只有把对象改成数值体积，通常的 `≤` 才是那个偏序。

### 例二：统计位数的函数

让 A 为所有 3 位二进制串，B 为 `{0,1,2,3}`，f 返回串里 `1` 的个数。`f(001)=f(010)=1`，所以不单射；`000`、`001`、`011`、`111` 分别取到 0、1、2、3，所以满射。若把陪域改成 `{0,1,2,3,4}`，对应规则仍是函数，却不再满射。

这能帮助理解程序接口：返回值类型类似陪域，实际能返回哪些值类似像集，但具体编程语言的类型系统还含有额外规则。数学关系与关系数据库并非同一层教程；表、主键、SQL 已在 [数据库基础](../../cs-basics/07-databases/) 中讲解，Java 容器操作见 [集合框架](../../java/02-collections/)。

## 通关自测

1. 令 `A={a,b}`、`B={b,c}`，求并集、交集、`A \ B` 及 `|A × B|`。
2. 在 `{0,1,2,3,4,5}` 上，定义 xRy 当且仅当二者除以 3 的余数相同。列出等价类，并说明传递性。
3. 正整数上的整除关系是偏序吗？2 与 3 可比较吗？
4. 函数 `f: {0,1,2} → {0,1,2,3}` 规定 `f(x)=x+1`，它是否单射、满射、有该陪域上的逆函数？

<details markdown><summary>参考答案</summary>

1. 并集 `{a,b,c}`，交集 `{b}`，差集 `{a}`；笛卡尔积有 4 个有序对。
2. `{0,3}`、`{1,4}`、`{2,5}`。若 x、y 余数相同，y、z 余数相同，则 x、z 余数也相同；自反与对称同样来自余数相等。
3. 是：每个正整数整除自身，互相整除的正整数相等，整除具有传递性。2 与 3 互不整除，所以不可比较；偏序不必是全序。
4. 单射，因为 `x+1=y+1` 推出 `x=y`。不满射，因为取不到 0；因而不存在从整个陪域到定义域的逆函数，但可在像集 `{1,2,3}` 上取逆。

</details>
