## 分组要看性质 {#_2}

缓存里有 6 个构建产物，按目标平台分组。两个产物属于同一平台，就把它们放进同一组。「体积不超过」却不能用同样的方法分组。差别在关系满足什么性质，不在容器类型。

在 `{0,1,2}` 上令 xRy 表示 `|x−y| ≤ 1`。它自反、对称，但 0R1 且 1R2，没有 0R2。把「差不超过 1」当成可以分组的等价关系是错的。把这个三元素集合的九对关系列完，只核对了这一个有限例子。

## 知识要点 {#_3}

### 集合与笛卡尔积 {#_4}

集合不计重复、没有顺序；序列计顺序，且可重复。`x ∈ A` 表示元素关系，`A ⊆ B` 表示 A 的每个元素都在 B 中；空集 `∅` 是每个集合的子集。

| 运算 | 含义 |
|------|------|
| `A ∪ B` | 属于 A 或 B |
| `A ∩ B` | 同时属于 A 和 B |
| `A \ B` | 属于 A 但不属于 B |
| `A × B` | 所有有序对 `(a,b)`，其中 a 属于 A、b 属于 B |
| `𝒫(A)` | A 的所有子集组成的集合，叫幂集 |

补集必须相对于一个全集 U，写为 `U \ A`。当 A、B 有限时，`|A × B| = |A||B|`；若 `|A| = n`，每个元素都有选或不选两种可能，所以 `|𝒫(A)| = 2ⁿ`。`∅` 与 `{∅}` 不同，前者没有元素，后者有一个元素。

### 二元关系与等价类 {#_5}

从 A 到 B 的二元关系是 `A × B` 的子集；A 上的关系是 `A × A` 的子集。写 `aRb` 表示有序对 `(a,b)` 属于 R。

| 性质 | 精确定义 |
|------|----------|
| 自反 | 对每个 a，都有 aRa |
| 对称 | aRb 推出 bRa |
| 传递 | aRb 且 bRc 推出 aRc |
| 反对称 | aRb 且 bRa 推出 a = b |

同时自反、对称、传递的关系叫等价关系，它把集合划分为互不相交且覆盖全集的等价类。把 a 的类写成 `[a] = {x ∈ A | aRx}`。自反保证 `a ∈ [a]`，所以这些类盖住 A。若 `[a]` 与 `[b]` 有公共元素 c，则 aRc 且 bRc。对称得到 cRb，再与 aRc 一起用传递得到 aRb。任取 bRx，由 aRb 与 bRx 得到 aRx，所以 `[b] ⊆ [a]`；反过来同样得到 `[a] ⊆ [b]`，两类相等。三条性质都用到了。缺传递时，上面的「差不超过 1」就是失败例子。

同时自反、反对称、传递的关系叫偏序，不要求任意两个元素可比较。例如集合之间的包含关系是偏序；`{a}` 与 `{b}` 可能互不包含。反对称不是「不对称」：相等元素仍然可以双向相关。

### 函数是有唯一性限制的关系 {#_6}

函数 `f: A → B` 要求 A 中每一个元素都有 B 中恰好一个输出。A 是定义域，B 是陪域；实际取到的输出组成像集 `f(A)`，像集不一定等于陪域。

- 单射：不同输入不会有相同输出；等价地 `f(a)=f(b)` 推出 `a=b`。
- 满射：陪域里的每个元素都被取到，即 `f(A)=B`。
- 双射：既单射又满射，因此有从 B 到 A 的逆函数。
- 复合 `g∘f` 先算 f 再算 g，要求 f 的输出能作为 g 的输入。

不满射时，陪域里有的元素没有原像，就不存在从整个陪域回到定义域的逆函数。把函数限制到像集上，可能变成双射，那时逆函数的定义域是像集，不是原来的陪域。

本页的关系是有序对组成的集合：同一个对不重复计入，一个对要么属于关系，要么不属于。PostgreSQL 的 `SELECT` 默认是 `SELECT ALL`，结果可以保留重复行；去掉重复要另写 `DISTINCT`。因此查询结果不是这里的集合，除非另外说明没有重复行。比较中的 NULL 也不是「这个有序对为假」：命题章所引的 PostgreSQL 文档写明，`=` 遇到 NULL 得到 unknown。关系代数教材常常先假设集合和二值成员关系；那个模型覆盖不了 SQL 的重复行和 NULL。数据库章的 SQL 练习不能倒过来当作本页定义已经成立的例子。2026-11-25 没有重开 PostgreSQL 的 SELECT 页。

## 小例题 {#_7}

### 例一：缓存分类为什么可行 {#_8}

产物为 `{a,b,c,d,e,f}`，平台标签依次是 `(X,Y,X,Z,Y,Z)`。定义 aRb 当且仅当二者平台标签相等。标签相等具有自反、对称、传递性，因此等价类是 `{a,c}`、`{b,e}`、`{d,f}`。

如果改成「体积不超过」，通常不对称，不能当等价关系；若两个不同产物体积相同，双向「不超过」也不推出产物本身相等，因此在产物集合上甚至不一定反对称。只有把对象改成数值体积，通常的 `≤` 才是那个偏序。

### 例二：统计位数的函数 {#_9}

让 A 为所有 3 位二进制串，B 为 `{0,1,2,3}`，f 返回串里 `1` 的个数。`f(001)=f(010)=1`，所以不单射；`000`、`001`、`011`、`111` 分别取到 0、1、2、3，所以满射。若把陪域改成 `{0,1,2,3,4}`，对应规则仍是函数，却不再满射。

这能帮助理解程序接口：返回值类型类似陪域，实际能返回哪些值类似像集，但具体编程语言的类型系统还含有额外规则，不能说 Java 容器或 SQL 已经满足这里的定义。数学关系与关系数据库并非同一层教程；表、主键、SQL 已在 [数据库基础](../../cs-basics/07-databases/) 中讲解，Java 容器操作见 [集合框架](../../java/02-collections/)。
