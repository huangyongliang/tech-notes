## 原创谜题：每个接口只巡检一次

巡检图的边为 `AB, BC, CA, AD`，表示四条双向接口。巡检器能否从某模块出发，每条接口恰好通过一次？如果还要求回到起点呢？先明确要覆盖的是**边**，不是「每个模块只到一次」。

## 知识要点

### 游走、迹、路与圈

不同教材对中文「路径」用词不完全一致，本专题固定如下约定；英文术语可帮助核对。

| 名称 | 允许的重复 |
|------|------------|
| 游走 walk | 相邻顶点必须有边，顶点和边均可重复 |
| 迹 trail | 不重复边，但可重复顶点 |
| 简单路 path | 不重复顶点，因此也不重复边 |
| 闭游走 | 起点与终点相同 |
| 圈 cycle | 长度至少为 3，除首尾相同外不重复顶点 |

长度按经过的边数计。单个顶点构成长为 0 的路；圈的顶点数与边数相同。一条游走若两次到达某个点，可删去两次到达之间的闭合段，仍连接原来的两端。每次删除使长度减少，最终得到简单路。因此「存在游走」与「存在简单路」在判断可达时等价。

### 连通分量、桥与割点

无向图中「存在游走能到达」包含长度 0 的自达，满足自反、对称、传递，因而把 V 划分成连通分量。图非空且只有一个分量时叫连通。

删除一条边若使连通分量数增加，该边叫桥；删除一个顶点及其关联边若使分量数增加，该点叫割点。圈上的边不是桥，因为被删边的两端仍能绕圈相连。实际网络的冗余要先明确故障对象是点还是边，二者不同。

### 欧拉迹与欧拉回路

欧拉迹恰好使用每条边一次；起终点相同的叫欧拉回路。对至少含一条边的有限无向图：

- 有欧拉回路，当且仅当所有非零度顶点处于同一连通分量，且每个顶点度为偶数。
- 有起终点不同的欧拉迹，当且仅当上述连通条件成立，且恰有两个奇度顶点；它们必须是两端。

必要性来自配对：闭迹里，中间点每用掉一条进入的边，就要再配一条离开的边；开放迹的起终点各剩一条未配对边。这一句只解释「为什么度数必须是偶数」，还没有证明「偶度时走不到一半就停住」。

充分性要看停住的那一刻。沿未用边往前走，允许重边，自环整条计 2。若停在不是本段起点的顶点 v，已经用掉的关联度数是奇数：经普通边进入的次数比离开的次数多 1，自环进出成对、只加偶数。v 原来的度是偶数，剩余度数仍是奇数，所以至少为 1，还能再走。起点处已用度数保持偶数，剩余可以降到 0；这时停住的是本段起点，走出的是闭迹。若还有未用边，由非零度部分连通，已走出的闭迹上必有一个仍有未用边的点，从那里再走一条闭迹并拼进去。每次消耗边，有限次后恰好用完。两个奇点时，可先增加一条连接它们的辅助边，允许形成重边；找到回路后切开这条辅助边，便得到原图的开放迹。例三是一次具体巡检，不要用「每进入一次都离开一次」代替上面这一步。

**有向图。** 弧有方向，自环同时记 1 次入度和 1 次出度。有向欧拉回路存在，当且仅当每个顶点入度等于出度，并且所有入度或出度不为 0 的顶点在忽略方向后属于同一个连通分量。必要性仍是配对，只是进入必须沿着弧。充分性只能顺着未用弧走，拼接方式和无向图相同。起终点不同的有向欧拉迹则改成：起点出度比入度多 1，终点入度比出度多 1，其余顶点平衡，连通性要求相同；添一条从终点指向起点的弧，就化成回路，再把这条弧切开。

[Euler Tours](https://vertex.degree/degrees/euler.html) 的推论用「除孤立点外弱连通，且每个顶点入度等于出度」表述回路。[Directed Graphs](https://algs4.cs.princeton.edu/42digraph/) 的习题则要求非零度顶点属于同一个强连通分量。在入度已经等于出度时，两者是同一范围：设 R 是从某个非零度顶点能到达的顶点集合。全体顶点平衡，所以跨出 R 的弧数等于跨入 R 的弧数。只要还有弧跨过边界，就会走到 R 外面，与 R 的定义矛盾。孤立点的入度和出度都是 0，可以留在这个分量之外。分层练习第 2 题是在用这个定理，不是在补定义。

若只有孤立点、但至少有一个顶点，约定长度 0 的游走已经覆盖全部空边集；本页不讨论没有顶点的空图的欧拉命名差异。

### 哈密顿问题换成了遍点

哈密顿路经过每个顶点恰好一次；哈密顿圈除首尾外经过每点恰好一次，并返回起点。后者要求至少 3 个顶点。

有哈密顿圈的图必须连通、每点度至少为 2，并且没有桥。但这些必要条件不能随便当成充分条件；哈密顿圈的存在性不是看奇偶度就能决定的。一般有限简单图的哈密顿圈判定是 NP 完全问题，精确定义在 [复杂度与归约](../14-complexity-reductions/) 中给出；这不等于所有小图都难，也不等于已经证明所有算法都慢。

**删点上界。** 若图有哈密顿圈，则删去任意 k 个顶点（1 ≤ k < n）后，剩下至多 k 个连通分量。本页的圈至少有 3 个顶点，所以上界从 n≥3 就成立，不必改成 n≥4。三角形删掉一个顶点后，剩下的两点仍有一条边，分量数是 1，没有超过 k。被删的点如果在圈上相邻，剩下的段数会少于 k，上界仍然只是「至多」。证明就三步：这 k 个点把圈切成若干段路，相邻两段之间至少夹着一个被删点，又因为圈绕回来，段数不超过 k；每一段内部连通；图的其余边只会把段连起来，不会把一段拆开。路的版本不绕回来，删 k 个点后至多 k+1 段。满足上界的图仍可能没有哈密顿圈。例四用蝶形图演示圈的版本，并说明它只是必要条件。

**和二部图有关的另一条界。** 顶点若能分成两侧、边只连接不同侧，沿圈就必须左右交替，长度不能是奇数。简单图里这样的圈最短是 4。因此二部图若有哈密顿圈，n 必须是偶数并且至少为 4，两侧的顶点数还要相等。3×3 网格可以这样染色，两侧是 5 和 4，n=9，所以没有哈密顿圈。这和删点上界是两条不同的必要条件，不要把 n≥4 写进删点引理。二部图的一般理论在 [二分图与匹配](../08-bipartite-matching/)，例四只把网格的染色算完。

## 小例题

### 例一：巡检路线与回路障碍

`D → A → B → C → A` 使用 AD、AB、BC、CA 各一次，是欧拉迹，但不是简单路，也不是欧拉回路。A 的度为 3、D 的度为 1，恰为两个奇点；这既解释起终点，也证明不能闭合。

给图再加一个孤立顶点 Z，原路线仍覆盖全部边；但不能成为覆盖全部顶点的哈密顿路，因为 Z 无法加入。这说明欧拉条件为什么只要求非零度部分连通。

### 例二：所有度都够也不保证哈密顿圈

把两个 4 点环各挑一个点，用一条额外的桥连接。每点度至少为 2，整体也连通。若哈密顿圈跨桥进入另一侧，必须再跨桥才能回起点，但圈不能重复这条边，因此不存在哈密顿圈。

本例反驳的是「连通且最小度至少 2 就足够」，没有声称「无桥就是充分条件」。遍历实现与队列/栈仍回 [DSA](../../cs-basics/06-data-structures-algorithms/)。

### 例三：从「走不下去」到拼接回路

巡检图允许重边和自环。顶点 A、B、C、D、E，边按编号为 `0:AB, 1:BC, 2:CA, 3:CD, 4:DE, 5:EC, 6:EE`，其中 6 号是 E 上的自环。

**先查前提。** 度数为 A=2，B=2，C=4，D=2，E=4（E 来自 DE、EC 各 1，自环 2）。全为偶数；所有边都在同一个连通分量里，且没有孤立点需要额外说明。按欧拉回路定理，回路存在。

**贪心会在哪里停下。** 从 A 出发，每次走编号最小的未用边：A→B→C→A。此时 A 的两条边都已用完，走不下去，但 CD、DE、EC、EE 还没走。

**为什么停不住中途点。** 看当前这段迹正停在顶点 v、且 v 不是这段起点的那一刻。已用度数这样计：普通边每用一条加 1，自环整条加 2（本例 E 上的自环就是 2）。这段迹还没离开 v，所以经普通边进入的次数比离开的次数多 1；自环进出成对，只加偶数。已用度数因此是奇数。v 原来的度是偶数，剩余度数 = 偶数 − 奇数，仍是奇数，故至少为 1，还有未用边可走。这一步不能换成「每进入一次都离开一次」：那句话说的是已经配对完成的访问，而此刻最后一次进入还没有离开。

**起点可以停下，并且迹是闭合的。** 起点出发前已用度数为 0，是偶数。之后每离开一次再回到起点，普通边成对，自环仍只加 2，已用度数保持偶数，剩余度数也是偶数，可以变成 0。上面停在 A 时剩余正好是 0，所以停点是这段的起点，走出的是闭迹。

**严格化：拼接。** 已走出的闭迹 `A,B,C,A` 经过 C，而 C 还有未用边。从 C 再走一条只用未用边的闭迹：C→D→E→C；回到 C 后 E 还剩自环，再从 E 拼入 E→E。把小闭迹逐个嵌回大闭迹，得到

`A, B, C, D, E, E, C, A`

共 7 条边，每条恰好一次。这就是知识要点里拼接证明的具体执行：上面的奇偶计算说明，偶度时这段迹只会在自己的起点走不动，因此是闭迹；连通保证只要有边未用，就有未用边挂在已走出的点上。

**算法实现。** 下面的 C 程序用显式栈完成同一件事（Hierholzer 算法）：栈顶顶点若还有未用边就沿边前进，否则出栈并记入回路。栈的用法见 [数据结构与算法](../../cs-basics/06-data-structures-algorithms/) 的「线性结构」，栈的 C 实现练习见 [问题求解](../../programming-basics/05-problem-solving/)。

```c
#include <stdio.h>

enum { N = 5, M = 7 };
static const char name[N] = {'A', 'B', 'C', 'D', 'E'};
static const int from[M] = {0, 1, 2, 2, 3, 4, 4};
static const int to[M] = {1, 2, 0, 3, 4, 2, 4}; /* 最后一条是 E 的自环 */

int main(void) {
    int deg[N] = {0};
    for (int e = 0; e < M; e++) {
        deg[from[e]]++;
        deg[to[e]]++; /* 自环在这里被加 2 */
    }
    for (int v = 0; v < N; v++) {
        if (deg[v] % 2 != 0) {
            printf("%c 是奇度顶点，没有欧拉回路\n", name[v]);
            return 1;
        }
    }

    int used[M] = {0}, next_edge[N] = {0};
    int stack[M + 1], circuit[M + 1], top = 0, len = 0;
    stack[top++] = from[0]; /* 从一个非零度顶点出发 */
    while (top > 0) {
        int v = stack[top - 1];
        while (next_edge[v] < M &&
               (used[next_edge[v]] ||
                (from[next_edge[v]] != v && to[next_edge[v]] != v))) {
            next_edge[v]++;
        }
        if (next_edge[v] == M) { /* v 已无未用边：出栈并记入回路 */
            circuit[len++] = v;
            top--;
        } else {
            int e = next_edge[v];
            used[e] = 1;
            stack[top++] = (from[e] == v) ? to[e] : from[e];
        }
    }
    if (len != M + 1) {
        printf("有边没有走到：非零度部分不连通\n");
        return 1;
    }
    for (int i = len - 1; i >= 0; i--) {
        printf("%c%s", name[circuit[i]], i > 0 ? " " : "\n");
    }
    return 0;
}
```

同一点的 Java 对照：

```java
class Hierholzer {
    static final int N = 5, M = 7;
    static final char[] name = {'A', 'B', 'C', 'D', 'E'};
    static final int[] from = {0, 1, 2, 2, 3, 4, 4};
    static final int[] to = {1, 2, 0, 3, 4, 2, 4}; // 最后一条是 E 的自环

    public static void main(String[] args) {
        int[] deg = new int[N];
        for (int e = 0; e < M; e++) {
            deg[from[e]]++;
            deg[to[e]]++; // 自环在这里被加 2
        }
        for (int v = 0; v < N; v++) {
            if (deg[v] % 2 != 0) {
                System.out.printf("%c 是奇度顶点，没有欧拉回路%n", name[v]);
                return;
            }
        }

        int[] used = new int[M], nextEdge = new int[N];
        int[] stack = new int[M + 1], circuit = new int[M + 1];
        int top = 0, len = 0;
        stack[top++] = from[0];
        while (top > 0) {
            int v = stack[top - 1];
            while (nextEdge[v] < M
                    && (used[nextEdge[v]] != 0
                        || (from[nextEdge[v]] != v && to[nextEdge[v]] != v))) {
                nextEdge[v]++;
            }
            if (nextEdge[v] == M) {
                circuit[len++] = v;
                top--;
            } else {
                int e = nextEdge[v];
                used[e] = 1;
                stack[top++] = (from[e] == v) ? to[e] : from[e];
            }
        }
        if (len != M + 1) {
            System.out.println("有边没有走到：非零度部分不连通");
            return;
        }
        for (int i = len - 1; i >= 0; i--) {
            System.out.printf("%c%s", name[circuit[i]], i > 0 ? " " : "\n");
        }
    }
}
```

程序输出 `A B C D E E C A`。实现上的三个对应关系：

- `deg` 检查对应「全为偶数」这一必要条件；`len != M + 1` 检查对应连通性：若非零度部分分成两块，从起点出发只能用完自己那一块的边。
- `used` 按边编号而不是按端点对标记，因此两条重边会被当作两条不同的边，自环也只会被使用一次。
- 每个点的 `next_edge` 只前进不后退，但这里每次都扫描整张边表，总代价是 `O(n·m)`；改用邻接表（见 [数据结构与算法](../../cs-basics/06-data-structures-algorithms/) 的「图」）后可降到 `O(n+m)`。

### 例四：遍边和遍点，四张图分开判

欧拉问题看度数和连通性；哈密顿问题要求每个**顶点**恰好一次，没有类似的度数判据。下面四张简单图逐一分开判断。

| 图 | 欧拉回路 | 欧拉迹 | 哈密顿圈 | 哈密顿路 |
|----|----------|--------|----------|----------|
| 蝶形图：三角形 ABC 与 CDE 共用 C | 有 | 有 | 无 | 有，如 A,B,C,D,E |
| 完全图 K₄ | 无，4 个奇度点 | 无 | 有 | 有 |
| 3×3 网格（9 点 12 边） | 无，4 个奇度点 | 无 | 无 | 有，蛇形走法 |
| 5 个点的圈 C₅ | 有 | 有 | 有 | 有 |

蝶形图和网格的「无哈密顿圈」需要证明，这里用一个自写的引理：

**引理**：若图 G 有哈密顿圈，则从 G 中删去任意 k 个顶点（1 ≤ k < n）后，剩下的图至多有 k 个连通分量。圈至少 3 个顶点，所以 n≥3 就够；n≥4 是上面二部图那条界，不是这条引理的假设。

1. 先只看哈密顿圈本身。圈上删去 k 个点，剩下的顶点沿圈被切成若干段连续的路；每两段之间至少夹着一个被删的点，所以段数至多为 k。
2. 每一段内部仍然连通，所以只看圈的边时，剩余部分至多 k 个连通分量。
3. G 的其余边只会把段连起来，不会把一段拆开，所以 G 删点后的连通分量数也至多为 k。

蝶形图删去 C 后剩 `{A,B}` 和 `{D,E}` 两块，k=1 却有 2 个分量，所以没有哈密顿圈；可它的全部顶点都是偶度且连通，欧拉回路存在。K₄ 正好相反。

3×3 网格用另一种障碍：按国际象棋棋盘交替染色，每条边连接异色两点，深色 5 个、浅色 4 个。哈密顿圈必须深浅交替，两色数量应相等，矛盾。这是二部图的计数论证，二部图本身见 [二分图与匹配](../08-bipartite-matching/)。

同一引理换成路的版本是「至多 k+1 个分量」（路被删 k 个点后至多 k+1 段）。注意引理只是必要条件：满足它的图仍可能没有哈密顿圈，判定一般图的哈密顿圈是 NP 完全问题，见 [复杂度与归约](../14-complexity-reductions/)。

1. 【入门】机房线路图：顶点 P、Q、R、T，边为 P–Q 两条（重边）、Q–R、R–P、R 上一条自环，T 是尚未接线的机柜。(a) 判断是否有欧拉回路、欧拉迹，若有给出一条。(b) 若把重边合并、删去自环，结论如何变化？
2. 【进阶】有向巡检。(a) 边为 `A→B, B→C, C→A, A→D, D→A`，是否存在每条边恰走一次、沿边方向的闭合巡检？给出路线。(b) 删去 `D→A` 后呢？(c) 边 `X→Y, Z→Y` 忽略方向时有欧拉迹，沿方向时有吗？写出有向图欧拉迹的完整条件。
3. 【进阶】两台核心交换机 H1、H2 各连接 5 台终端 L1 到 L5，终端之间、核心之间都不相连（即 K₂,₅）。(a) 是否有欧拉迹？(b) 是否有哈密顿圈？(c) 是否有哈密顿路？

<details markdown><summary>参考答案</summary>

1. (a) 度数为 P=3（两条重边加 RP），Q=3，R=4（QR、RP 各 1，自环 2），T=0。非零度部分连通，奇度点恰好 P、Q 两个，所以没有欧拉回路，有从 P 到 Q 的欧拉迹，如 `P, Q, P, R, R, Q`：依次用第一条 PQ、第二条 PQ、PR、自环、RQ，共 5 条边。T 度为 0，不影响结论；若要求「经过每个机柜」，那就是另一个问题。(b) 合并重边、删去自环后，顶点仍是 P、Q、R、T，T 没有被删掉，度仍为 0。非零度子图是三角形 PQR，只有这三点的度都是 2，不是整张图每个点度都是 2。非零度部分连通且这些度为偶数，所以有欧拉回路 `P, Q, R, P`，T 不在这条回路上。同一份记录换成简单图模型，结论从「只有迹」变成「有回路」，所以必须先写明模型。
2. (a) 入度、出度：A 出 2 入 2，B、C、D 各出 1 入 1；忽略方向连通。全部相等，故有有向欧拉回路，如 `A, B, C, A, D, A`。(b) 删去后 A 出 2 入 1，D 出 0 入 1，其余平衡，有从 A 到 D 的有向欧拉迹 `A, B, C, A, D`，没有回路。(c) 没有：Y 入度 2、出度 0，任何有向迹最多从 Y 离开 0 次，却要进入 Y 两次，只能在终点进入一次。有向欧拉回路的条件是：每点入度等于出度，且所有非零度顶点在忽略方向后连通（在入出度相等时，这等价于它们同属一个强连通分量）。有向欧拉迹（起点终点不同）的条件是：起点出度比入度多 1，终点入度比出度多 1，其余点平衡，连通性要求同上。证明可补一条从终点指向起点的边，化归为回路情形。
3. (a) H1、H2 度为 5，各 L 度为 2，图连通，奇度点恰好两个，有从 H1 到 H2 的欧拉迹，如 `H1, L1, H2, L2, H1, L3, H2, L4, H1, L5, H2`，共 10 条边。(b) 没有：删去 H1、H2（k=2）后剩 5 个孤立的终端，5 > 2，违反例四引理。(c) 也没有：路的版本要求删 2 个点后至多 3 个分量，而这里有 5 个。直观上，哈密顿路必须让终端和核心交替出现，7 个点中终端占 5 个，两台核心不够把它们隔开。这道题有欧拉迹却连哈密顿路都没有，正好说明两类问题不能互相推出。

</details>

## 通关自测

1. 5 个顶点组成单个环，有欧拉回路吗？有哈密顿圈吗？两者理由相同吗？
2. 两个互不相连的 4 点环，每点度数都为偶数，是否有一个使用全部边的欧拉回路？
3. 3 点链 A–B–C 有哪些奇度点？能否有欧拉迹、欧拉回路、哈密顿路、哈密顿圈？
4. 证明任意含圈的无向图中，圈上的一条边不是桥。不要只画一个例子。

<details markdown><summary>参考答案</summary>

1. 都有。沿环一周既把各边用一次，也把各点访问一次；欧拉的条件按度和边连通性，哈密顿则由这条遍点圈直接见证，不能把两类一般判定混为一谈。
2. 没有。一个游走不能跨越没有边相连的两个分量；偶度条件不够。
3. A、C 为奇点。沿 A–B–C 是欧拉迹也是哈密顿路；不能有欧拉回路，也不能有哈密顿圈。
4. 设被删边为 uv。圈除 uv 之外仍含一条 u 到 v 的路；任何原来使用 uv 的游走都可把这一步换成该替代路，因此删边不破坏原先的可达关系，分量数不增加。

</details>
