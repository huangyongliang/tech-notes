## 原创谜题：四步构建的先后顺序

步骤为 P「准备元数据」、G「生成代码」、T「测试」、D「打包」。要求 P 在 G、T 之前，G、T 都在 D 之前，得到边 `P→G, P→T, G→D, T→D`。G 与 T 谁先？能否只通过给步骤编号就解决一切调度问题？

## 知识要点

### 有向图与强弱连通

有向边 `(u,v)` 与 `(v,u)` 不同。入度是指向某点的边数，出度是从某点出发的边数。每条有向边恰好贡献一次入度和一次出度，所以入度和、出度和都为 m，自环若存在也各计一次。

有向游走必须顺边方向。有向图忽略方向后连通，叫弱连通；每一有序点对都能沿方向到达，叫强连通。`A→B` 弱连通，却不是强连通。

用「相互可达」关系分出的等价类叫强连通分量；长度 0 的路保证每点至少和自己同类。把每个分量缩成一个点，并在原图存在**直接跨分量边**时加一条对应边、删除分量内部边，得到缩点图。缩点图必是 DAG：若不同分量之间存在有向圈，它们实际上相互可达，应合成同一分量，矛盾。

这里特意按直接跨分量边定义缩点图；有的材料选择用跨分量可达关系加边，那会多出传递边，但同样无环，不要在实现时混用。

### DAG 与拓扑序的等价关系

有向圈沿方向闭合，除首尾外不重复顶点。与简单无向图的圈不同，两个相反方向的边可形成长为 2 的有向圈；若模型允许自环，自环也算长为 1 的有向圈。

DAG 是没有有向圈的有向图；其底层无向图可以有圈。拓扑序把全部顶点排成线性顺序，使每条边都由较早指向较晚。

**定理**：有限有向图有拓扑序，当且仅当它是 DAG。

若有拓扑序，沿边位置严格变大，不可能绕圈返回。反过来，非空有限 DAG 必有入度 0 的点：否则不断找前驱，有限顶点迫使重复，产生有向圈。取出一个入度 0 的点放在序列开头，剩余仍是 DAG，继续即可。空图有空拓扑序，但没有「至少一个源点」。用出度同理可得非空 DAG 至少有一个汇点。

### Kahn 算法：删源点为什么安全

维护剩余图的入度，把当前所有入度 0 的点加入待处理集合；每次取一个输出，删除它的所有出边，使新入度 0 的点也入队。

不变式是：已输出的顺序不违反任何依赖；剩余入度只统计来自未输出点的边。每轮至少输出一个点，故有限次终止。如果还有点却没有入度 0 的点，就存在圈，无法输出完整拓扑序。邻接表加队列的实现时间为 `O(n+m)`，每点出队一次、每边处理一次。

剩余点不一定全部在圈上；依赖圈的下游也会被阻塞。若要精确定位循环依赖，应进一步找强连通分量，而不是把剩余点统统指认为圈成员。

### 拓扑递推与偏序

DAG 中允许长度 0 的可达关系是偏序：自反、传递；若两点不同却双向可达，会有有向圈，违反反对称。拓扑序是这个偏序的一种线性扩展，不必唯一。

例如计算从起点 s 到各点的路径条数：令 ways(s)=1，其余为 0；按拓扑序，把每点的 ways 值加到各后继。等价地，非 s 顶点的路径数是各前驱路径数之和。有限 DAG 不会因循环产生无限多条游走；大图仍可能产生很大的计数，实现须注意整数范围。

## 小例题

### 例一：两个合法顺序不是同一个计划

构建例子可取 `P,G,T,D` 或 `P,T,G,D`。从 P 到 D 有 `P→G→D`、`P→T→D` 共 2 条路径。但这两条路径不是「两种完整调度方案」的一般计数公式，只是在本例数字碰巧相同。

拓扑序只满足先后约束；若 G 和 T 都要独占同一台机器，就不能同时做。最短工期、资源容量、公平性是额外优化条件，不能由「有拓扑序」自动解决。

### 例二：圈后的无辜下游

边为 `A→B, B→A, B→C, C→D`。四点入度都不为 0，Kahn 一开始就卡住。但真正的非平凡强连通分量只有 `{A,B}`；C、D 各自成分量，并不在圈上。缩点后是 `{A,B}→{C}→{D}`。

这套语言能帮助阅读依赖系统，但 [Git 的提交/分支操作](../../cs-basics/04-git/) 与 [操作系统调度](../../cs-basics/02-operating-systems/) 仍有自己的规则；本关不把数学模型当成某个产品实现规范。
