## 原创谜题：直达不一定最快

静态有向通信图的边和延迟为 `s→a:6, s→b:2, b→a:1, a→t:2, b→t:8`。直达 a 的延迟是 6，但先去 b 再去 a 只需 3；到 t 的最佳路线是 s–b–a–t，费用为 5。只按边数分层或只挑某条最短边，都可能答错。

## 知识要点

### 距离与松弛的含义

本关研究有限有向带权图上的单源最短游走费用；对于可达且不受相关负圈影响的目标，总能删掉非负圈得到不重复顶点的最短路。不可达的点记为正无穷。若 s 可到达某负圈，且该圈还能到达目标 t，就能绕圈任意多次，使到 t 的费用无下界，此时没有有限最短距离。

算法的暂存标签 d(v) 表示已找到的某条 s 到 v 的路径或游走费用，所以它是最优距离的**上界**，不保证已经最优。松弛边 `u→v` 即尝试 `d(v)=min(d(v),d(u)+w(u,v))`，仅当 u 标签有限时进行。任何更新都能拼接出真实游走，因此不会凭空找到比所有合法游走更小的虚构答案。

### BFS：层号为什么最短

无权图或所有边权同为 1 时，用 FIFO 队列按距离层次处理。第一次发现邻点时立刻标记、设距离并入队，不等出队才标记。

证明不变式是队列按已发现层号非递减排列，且第一次到达 v 的长度等于最少边数。若某点本可更早到达，其更短路径的前驱应在更早一层已被处理，便早已发现它，矛盾。邻接表下时间为 `O(n+m)`；邻接矩阵逐行扫描则通常是 `O(n²)`，不能不谈表示方式就报复杂度。

### Dijkstra：非负权在哪里起作用

Dijkstra 反复选未确定点中标签最小的 u，确定其距离，再松弛其出边。这里说的是「确定后不再修改」的标准版本，要求边权非负。

设已确定集合 S 的距离正确。看一条 s 到 u 的最短路，取它从 S 跨出的第一个点 y；前驱 x 已被正确确定并松弛过，故 y 的标签不大于这段最短路前缀费用。非负权保证前缀费用不大于整条路费用，所以 `d(u)≤d(y)≤dist(u)`；又因标签来自真实路径有 `d(u)≥dist(u)`，故恰好相等。源点先以 0 确定作为基例；只对有限可达标签继续处理。

关键不是「每一步选了最小边」，而是选了**最小暂定总距离**。邻接表与支持减小键值的二叉堆实现可在 `O((n+m) log n)` 时间完成；朴素数组选择点则为 `O(n²+m)`，常写作稠密图下的 `O(n²)`。

### DAG 与 Bellman–Ford

DAG 按拓扑序松弛即可：处理一个点时所有入边前驱都已处理，归纳可得距离正确；允许负权，因为不会绕圈。邻接表下时间 `O(n+m)`。

一般有向图允许负边时，可用 Bellman–Ford。为看清证明，采用**同步轮次**：本轮只从上一轮标签更新。令 dₖ(v) 为最多 k 条边的 s 到 v 游走的最小费用，初值 d₀(s)=0，其余无穷。每条最优游走要么不超过 k−1 条边，要么是前一条游走加最后一边，于是得到递推并证明第 k 轮标签的含义。

没有源点可达负圈时，可删圈取得至多 n−1 边的最优简单路，所以 n−1 轮足够。再一轮若仍可改善，表明有源点可达负圈；其影响只传到从这些负圈可达的目标，并不让所有点答案都失效。逐边原地更新的常见实现也正确，但一轮可能传播多条边，不能声称它的标签「恰好等于最多本轮数条边的最优值」。

## 小例题与可运行验证

### 例一：手算非负图

初始仅 s 为 0。确定 s 后，a 为 6、b 为 2；确定 b 后，a 改为 3、t 为 10；确定 a 后，t 改为 5；最后确定 t。这个顺序及证明依赖所有权重非负，并不模拟实际网络中不断变化的拥塞。

下面是 Python 3 的同步 Bellman–Ford 教学版，额外存一份数组以保留轮次不变式；代码无第三方依赖。参数 edges 是可重复遍历的边三元组列表，权重使用整数；不处理浮点 NaN 或无穷权重。

```python
from math import inf


def bellman_ford(n, edges, source):
    assert 0 <= source < n
    assert all(0 <= u < n and 0 <= v < n for u, v, _ in edges)
    dist = [inf] * n
    dist[source] = 0
    for _ in range(n - 1):
        nxt = dist.copy()
        for u, v, weight in edges:
            if dist[u] != inf:
                nxt[v] = min(nxt[v], dist[u] + weight)
        dist = nxt
    reachable_negative_cycle = any(
        dist[u] != inf and dist[v] > dist[u] + weight
        for u, v, weight in edges
    )
    return dist, reachable_negative_cycle


edges = [(0, 1, 6), (0, 2, 2), (2, 1, 1), (1, 3, 2), (2, 3, 8)]
assert bellman_ford(4, edges, 0) == ([0, 3, 2, 5], False)
assert bellman_ford(3, [(0, 1, 2), (1, 2, -4)], 0) == ([0, 2, -2], False)
assert bellman_ford(3, [(1, 2, -2), (2, 1, 1)], 0) == ([0, inf, inf], False)
assert bellman_ford(3, [(0, 1, 0), (1, 2, -2), (2, 1, 1)], 0)[1]
print("shortest-path checks passed")
```

本程序返回负圈标志为真时，标签只代表有限轮次内的结果，**不能当作全部最终最短距离**；它没有继续标出每个受影响目标。时间为 `O(nm+n²)`（同步复制数组的代价也算入），额外空间 O(n)。这里按一次整数运算为常数计算，大整数的位运算成本另计。常见原地 Bellman–Ford 计入初始化和外层循环后为 `O(nm+n)` 时间，当 m≥1 时简写 `O(nm)`，额外空间 O(n)；本例不为简短忽略数组复制成本。

### 例二：负边击穿「确定就不改」

边为 `s→a:2, s→b:5, b→a:−4`。标准 Dijkstra 会先把 a 固定为 2，却漏掉 s–b–a 的费用 1，前面的非负前缀论证正是在这里失效。图没有圈，因此 DAG 方法和 Bellman–Ford 都可正确处理。

若另有源点可达负圈，但从圈不能到达 a，不能据此宣称 a 也无有限答案；必须检查对目标的影响范围。容器实现、堆与遍历基础回 [DSA](../../cs-basics/06-data-structures-algorithms/)，证明模板回 [归纳与不变式](../03-proofs-induction/)。

1. 所有边权都为 7，BFS 能否用于求最小费用？若边权有 1 和 7 两种呢？
2. 在例二加入 `a→t:3`，求 s 到 t 的最短费用；图中有负边就一定有负圈吗？
3. 证明最短路的一个子段也必须最短，明确假设相关最短距离有限。
4. n−1 轮以后还能改善，证明中为什么需要顶点数 n？返回负圈标志是否意味着每个目标都费用无下界？

<details markdown><summary>参考答案</summary>

1. 相同正权时最少边数与最小费用等价，BFS 距离乘 7 即可。两种不同权重时不保证，边数少可能费用更大。
2. 走 s–b–a–t，费用 `5−4+3=4`。有负边不等于有负圈，本例仍是 DAG。
3. 若某子段可替换成更便宜的同端点游走，替换后得到更便宜的完整游走，违背最优。不存在相关负圈时可删掉非负圈得到不更贵的路，所以结论成立。
4. 至多 n−1 边覆盖所有简单路；超过该长度的游走会重复顶点，才需要借助圈来继续改善。负圈只影响源点能到达且从该圈还能到达的目标，不是全部目标。
