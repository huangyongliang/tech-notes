## 从一个不可能的万能检查器开始

设想工具 H 能读取任意程序 P 和输入 x，总在有限时间内准确回答「P 在 x 上会不会结束」。它比编译器警告、单元测试或运行超时强得多。这个工具并不存在；结论有严格的模型、量词与证明，不能简写成「所有程序都无法分析」。

## 知识要点

### 图灵机是模型，不是某台机器

标准图灵机由有限控制状态、读写头和可无界扩展的纸带组成；每步按当前状态与纸带符号读写、移动并转移。输入是有限串，某次运行用过的纸带部分在每个有限时刻仍是有限的，但没有预先固定的总内存上界。

程序和输入可编码成字符串，通用图灵机可以模拟被编码的机器。多带机等常见变体在**可计算哪些函数**上与标准模型等价，运行效率则可能不同。

Church–Turing 论题主张直觉上的有效机械计算都能由图灵机完成。它把非形式化概念与形式模型联系起来，是论题而不是在一个形式系统里直接证出的同类数学定理；特定形式模型之间的等价性则可以证明。

现实计算机内存有限；停机不可判定的通用结论讨论的是允许无界内存和任意程序长度的算法模型。对固定有限状态系统，重复状态检查往往可以判定终止；不能把两种设定混在一起。

### 可判定与可识别

把判定问题写成语言 L，即所有答案为「是」的编码集合。

- L **可判定**：存在算法，对每个输入都停止，并正确接受属于 L 的输入、拒绝不属于 L 的输入。
- L **可识别**：存在算法，对属于 L 的输入终会接受；对不属于 L 的输入可以拒绝，也可以永不停止。

每个可判定语言都可识别，反向不成立。如果 L 及其补语言都可识别，可交替模拟两个识别器，每个轮流走一步；恰好一个最终接受，所以可以判定 L。这里不能先把一个识别器运行到结束再启动另一个，否则第一个可能一直不结束。

### HALT 能识别，却不能总判定

定义 `HALT={⟨P,x⟩ : P 在输入 x 上最终停止}`，只讨论有效编码；无效编码可直接拒绝。识别它很简单：模拟 P(x)，如果停止就接受。如果不停止，模拟也会一直继续，因此这只是识别器。

**停机问题不可判定**的对角证明：假设存在总停机且正确的判定器 H。构造程序 D，输入是程序编码 p：若 H 判断 p 在自身编码 p 上停止，D 就永远循环；若 H 判断不会停止，D 就立刻停止。现在把 D 自己的编码 d 输入 D。

- H 若说 D(d) 会停止，按 D 的定义它便不停止。
- H 若说不会停止，D(d) 反而停止。

两种回答都错，因此假设的 H 不存在。构造 D 是因为程序可读入和模拟编码，不是依赖 C 函数指针的某种特殊技巧。证明只排除一个适用于**全部**程序和输入的万能判定器；许多具体程序仍可通过循环变式等方法证明终止。

### 归约：把已知难题变成目标问题

本关使用可计算多对一归约：若存在总可计算映射 f，使 `x∈A` 当且仅当 `f(x)∈B`，写作 `A≤ₘB`。那么若 B 可判定，就能先算 f 再运行 B 的判定器，从而判定 A。

所以要证明 B 不可判定，应从一个已知不可判定的 A **归约到 B**，而不是只做反方向。这里 f 只要求总可计算，不要求多项式时间；下一关的复杂度归约会加强效率条件。

## 小例题

### 例一：超时记录不是反例证明

某程序运行 10 秒仍未结束，能推出它不终止吗？不能；它可能第 11 秒结束。设置运行预算是有用的工程保护，但它得到的是「预算内未完成」，不是关于无限未来的数学判定。

相反，若一个固定整数计数器从 n 开始，每次在大于 0 时减 1，且 n 为给定非负整数，就可用严格下降的自然数证明它必终止。这与停机不可判定没有矛盾；见 [证明与归纳](../03-proofs-induction/)。

### 例二：把停机转成「是否触发完成标记」

设目标问题 B 问：某程序在给定输入上，是否曾执行到一个特别的完成标记指令。给定任意 HALT 实例 `⟨P,x⟩`，自动生成新程序 Q：先模拟 P(x)，模拟停止后才执行该标记。Q 的固定输入可设为空串。

P(x) 停止，当且仅当 Q 会执行标记；生成 Q 的过程只是在代码外包一层模拟器，有限时间即可完成。如果有万能标记判定器，就能判定 HALT，因此 B 不可判定。这里使用的是模型内的特殊指令，不是去真实设备上执行操作；不需要真的让 Q 运行到结束才能生成 Q。

## 和工程、AI 的衔接

静态分析器可在限定语言上精确分析，也可对更广输入保守近似或返回「未知」；停机定理不禁止这些工具。Java 程序、微服务调用或 AI Agent 的步骤预算可以提供运行边界，却不能让一个声称覆盖任意程序的检查器绕过对角论证。加入 AI 预测也不等于获得对所有输入都正确且总停机的证明。

## 通关自测

1. 「某程序存在一个输入会停机」与「给定程序在给定输入上会停机」是不是同一句话？写出前者的量词。
2. HALT 的模拟识别器在不属于 HALT 的输入上会发生什么？能否因此称它为判定器？
3. 已知 A 不可判定且 `A≤ₘB`，能推出什么？只知道 `B≤ₘA` 时又能推出什么？
4. 固定系统只有 K 个完整状态且确定运行、没有外部输入；若运行超过 K 次状态访问仍未停止，重复完整状态为何能证继续循环？这为何不推翻停机定理？

<details markdown><summary>参考答案</summary>

1. 不同；前者是 `∃x，P(x) 停机`，而后者指定了一个 x，不能随意换量词或输入。
2. 它会一直模拟而不结束，所以不能作总停机判定器。
3. 前者推出 B 不可判定，否则可组合判定 A。仅后者不能推出 B 不可判定，一个很简单的可判定问题也可能归约到不可判定问题。
4. K+1 次非停机状态访问必重复。确定性且无新外部输入保证之后后继完全相同，将重复同一段；但图灵机模型没有预先固定的完整状态总数上界，因为纸带内容可无界变化。
