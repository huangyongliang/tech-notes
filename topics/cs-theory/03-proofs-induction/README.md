## 先拆结论，再选方法

要证明一个断言，先写出对象范围、假设和目标。「存在」可尝试给出见证；「所有」应取任意对象；「当且仅当」要检查两个方向。反驳全称断言只需一个合法反例，但反驳存在断言要排除所有候选。

直接证明从假设出发推出结论；逆否证明改证 `¬Q → ¬P`；反证法假定目标不成立，再推出矛盾。分类讨论必须覆盖所有情况，不能把最难的分支漏掉。双重计数则从两个角度数同一集合，后面的握手定理会再次使用。

## 小例题与证明工具

### 例一：直接与逆否

若整数 a、b 都能被 3 整除，令 `a=3r`、`b=3s`，则 `a+b=3(r+s)`，因此和也能被 3 整除。这是展开定义的直接证明。

证明「若整数 n² 为奇数，则 n 为奇数」可改证逆否：若 n 为偶数，写 `n=2k`，则 `n²=4k²=2(2k²)` 为偶数。不要只检查几个平方，也不要把「n 为奇数推出 n² 为奇数」当成原结论的证明。

### 普通归纳：一小步怎样覆盖无限多项

设要证对所有整数 `n ≥ n₀` 都成立的 P(n)：

1. 证明基例 P(n₀)。
2. 取任意 `k ≥ n₀`，在假设 P(k) 的前提下证明 P(k+1)。
3. 由归纳原理得出对所有 `n ≥ n₀` 成立。

例如一个日志缓冲区第 i 次写入 `3i+1` 字节，i 从 0 开始。理想数学模型下，写 n 次的总字节数为 `S(n)=n(3n−1)/2`。基例 `S(0)=0`；假设 k 次成立，再写 `3k+1` 字节，总数为 `k(3k−1)/2+3k+1=(k+1)(3k+2)/2`，正是目标公式。

这是数学整数上的结论；实现时还要检查机器整数溢出和分配失败，不能把抽象证明直接当成 C 内存安全证明。

### 例二：强归纳与拆分合并

若合并器每次只能把两个非空包合成一个包，从 n 个初始包得到一个包，任意完整二叉合并方案都恰有 `n−1` 次合并。

以 n 强归纳。n 为 1 时无需合并。n 大于 1 时，最后一次操作合并了两个子方案，它们分别包含 a、b 个初始包，`a+b=n` 且 `1 ≤ a,b < n`。由强归纳假设，前两部分分别用了 `a−1`、`b−1` 次，加最后一次，总数为 `n−1`。

强归纳允许使用此前所有更小规模的结论，不只是 P(n−1)；它与普通归纳在自然数上证明能力相同。这里须说明 a、b 确实更小，且子方案满足原题条件。

### 良序与最小反例

**良序原理**：每个非空自然数子集都有最小元素；本专题自然数包含 0。不能把它套到正实数上，因为正实数集合没有最小正数。

上面的字节公式也可用最小反例证明：若反例存在，取最小反例 m。基例保证 `m>0`；m−1 不可能是反例，故可用公式计算前 m−1 次，再加 `3m−2`，推出第 m 次也满足公式，矛盾。最小反例、强归纳、普通归纳在此语境下互相对应，并不是三种相互冲突的数学规则。

### 不变式和终止性要分开

考虑数学伪代码：从 `i=0, s=0` 开始，当 `i<n` 时依次执行 `s=s+3i+1`、`i=i+1`。循环不变式是「完成 i 次后，`s=i(3i−1)/2`，且 `0≤i≤n`」。

- **初始化**：i 为 0 时成立。
- **保持**：按普通归纳的代数计算，一轮后仍成立。
- **退出后**：i 等于 n，所以 s 是目标总数。
- **终止**：非负整数 `n−i` 每轮严格减少，不能无限下降。

前三点证明「如果停止则结果正确」，再补终止性才得到总正确性。一个过程即使保持不变式，也可能永远不退出。后续 [最短路证明](../11-shortest-path-proofs/) 会重复这套框架；C 调试工具仍回 [工具与调试](../../programming-basics/04-tools-debugging/)。

## 常见误区

- 归纳假设不能直接假设正在证明的 P(k+1)。
- 从「某个 k 成立」不能跳到「任意 k 都成立」。
- 归纳步如果一次跳 2，就必须分别覆盖两个起始奇偶链。
- 「每轮更小」还要说明下降量所在集合良基；正实数可无限减半。

## 通关自测

1. 证明：若整数 a、b 均为偶数，则 `a−b` 为偶数。
2. 一个计数器起始为 5，每次增加 4。用归纳证明第 n 次操作后为 `5+4n`，范围为 `n≥0`。
3. 二叉合并例子中，为什么只假设规模 n−1 的结论未必能直接完成那一步？为什么允许空子方案会破坏上述证明写法？
4. 过程不断把正实数 x 替换成 x/2。仅凭「严格下降且有下界 0」，能证明有限次后到 0 吗？

<details markdown><summary>参考答案</summary>

1. 令 `a=2u`、`b=2v`，则 `a−b=2(u−v)`；u−v 是整数，所以差为偶数。
2. n 为 0 时是 5。假设 k 次后为 `5+4k`，再增加 4 得 `5+4(k+1)`，故对所有非负整数成立。
3. 子规模 a、b 可能都不等于 n−1，强归纳假设可同时覆盖它们。若允许某侧包含 0 个初始包，另一侧可能仍为 n，不能援引「更小规模」，并且问题本身的操作规则也已改变。
4. 不能。数学实数模型下，每个有限步后仍为正，只是趋近 0；「非负整数严格下降」与「有下界的实数严格下降」不是同一个终止依据。
