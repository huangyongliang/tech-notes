## 知识要点

### 键盘与打字

- **基准键位**：左手食指放 `F`、右手食指放 `J`（这两个键上有小凸起），其余手指依次排开，每个手指负责固定的一列。
- **先准后快**：前两周只追求不看键盘、不出错，速度自然会上来。
- **程序员常用符号**要专门练：`{ } [ ] ( ) < > ; : " ' / \ | _ - = + * & ^ % $ # @ !`，写代码时它们和字母一样多。
- 中文输入法要会快速切换中英文（常见是 `Shift` 键），写代码时一律用英文标点，中文全角符号 `，；（）` 会让程序报错。

### 文件、目录与路径

文件系统是一棵树：最顶层是根，下面是一层层的目录（文件夹），文件挂在目录里。

| 系统 | 根 / 起点 | 用户目录示例 | 分隔符 |
|------|-----------|--------------|--------|
| Windows | 盘符 `C:\` | `C:\Users\alice\Documents` | `\` |
| macOS | `/` | `/Users/alice/Documents` | `/` |
| Linux | `/` | `/home/alice/Documents` | `/` |

- **绝对路径**从根开始写全，在哪儿用都指向同一个位置。
- **相对路径**从「当前所在目录」出发：`.` 表示当前目录，`..` 表示上一级。例如当前在 `Documents`，`../Downloads` 就是同级的 `Downloads`。
- **扩展名**（`.txt`、`.jpg`）告诉系统用什么程序打开文件。Windows 默认隐藏扩展名，建议在资源管理器「查看」里打开「文件扩展名」，否则容易被 `报告.pdf.exe` 这类伪装文件骗到。
- 给文件和目录起名时，学习编程阶段建议只用英文字母、数字、`-` 和 `_`，不要用空格和中文，后面在命令行里会省很多麻烦。

### 安装与卸载软件

- **优先官方渠道**：软件官网、系统自带应用商店（Microsoft Store、Mac App Store）。搜索引擎里的「高速下载」按钮常常捆绑广告软件。
- **常见安装包**：Windows 的 `.exe`、`.msi`；macOS 的 `.dmg`（打开后把应用拖进「应用程序」）、`.pkg`；Linux 用发行版的软件包。
- **卸载**走系统设置（Windows「设置 → 应用」、macOS 把应用拖到废纸篓），不要直接删安装目录。
- **包管理器**用一条命令安装软件，是程序员的常用方式：

```bash
# Windows 10 / 11（winget，在 PowerShell 或终端中运行）
winget install --id Git.Git -e

# macOS（需要先按 brew.sh 的说明安装 Homebrew）
brew install git

# Debian / Ubuntu Linux
sudo apt install git
```

### 压缩包

`.zip` 是各系统都能直接打开的压缩格式；`.7z`、`.rar` 需要额外软件；`.tar.gz` 在 Linux 和 macOS 上常见。解压前先看清楚会解到哪个目录，避免把几百个文件撒在桌面上。

### 常用快捷键

| 功能 | Windows | macOS |
|------|---------|-------|
| 复制 / 剪切 / 粘贴 | `Ctrl` + `C` / `X` / `V` | `Cmd` + `C` / `X` / `V` |
| 撤销 / 重做 | `Ctrl` + `Z` / `Ctrl` + `Y` | `Cmd` + `Z` / `Cmd` + `Shift` + `Z` |
| 全选 / 保存 / 查找 | `Ctrl` + `A` / `S` / `F` | `Cmd` + `A` / `S` / `F` |
| 切换应用 | `Alt` + `Tab` | `Cmd` + `Tab` |
| 打开文件管理器 | `Win` + `E` | 在 Dock 点「访达」 |
| 全局搜索 | `Win`（直接输入） | `Cmd` + `Space` |
| 截图 | `Win` + `Shift` + `S` | `Cmd` + `Shift` + `4` |
| 锁屏 | `Win` + `L` | `Ctrl` + `Cmd` + `Q` |

> [!TIP]
> 每周只刻意练 3 个新快捷键，用一周后就会变成肌肉记忆。浏览器里的 `Ctrl` / `Cmd` + `L`（跳到地址栏）、`T`（新标签页）、`W`（关闭标签页）也非常常用。

### 备份

重要文件至少有两份，放在不同地方（例如电脑 + 云盘或移动硬盘）。常说的「3-2-1 原则」是：3 份副本、2 种介质、1 份异地。写代码的文件以后用 [Git](../../cs-basics/04-git/) 管理并推送到 GitHub，也是一种备份。

## 常见误区

- **把所有文件都放在桌面或「下载」里**：时间一长找不到东西。按「项目 / 年份 / 类型」建目录，下载后立即归档。
- **在文件名里用空格和中文**：图形界面没问题，到了命令行要处处加引号，有些工具还会出错。
- **一路点「下一步」安装**：很多安装程序默认勾选了附带软件，注意看每一页。
- **用 `Ctrl` + `C` / `V` 却不会撤销**：误操作后第一反应应该是 `Ctrl` / `Cmd` + `Z`，而不是手动修复。

## 实践任务

1. 在 TypingClub 或 Monkeytype 上做一次测速，记下起点速度；之后每天练 15 分钟，两周后再测一次。
2. 打开文件扩展名显示，在「文档」下建立 `learning/getting-started/` 目录，写下它的绝对路径。
3. 用包管理器（winget、Homebrew 或 apt）安装一个软件，例如 Git 或 VS Code，再用系统设置卸载一个不用的软件。
4. 把一个文件夹压缩成 `.zip`，发给自己（邮件或网盘），再下载解压到另一个目录。
5. 在「我的电脑说明书」里补充：常用软件清单、目录整理规则、你最常用的 10 个快捷键。
